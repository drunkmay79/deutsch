# Gutachter-Deutsch

Курс немецкого B1–B2 на 13 недель для оценщика недвижимости: профессиональная лексика
(оценка по ImmoWertV, Grundbuch, банк и Beleihungswert), грамматика на профессиональном
материале, много устной практики и разговор с Claude: ролевые игры, собеседования
в Sparkasse и оценочной фирме.

Каждый день — 2 сессии по 45 минут. Методика и план — в [docs/КУРС.md](docs/КУРС.md).

## Где работает

Приложение публикуется как страница (artifact) на claude.ai. Там оно получает:
- **Claude** (`sample`): собеседник в чате, проверка свободных ответов, разбор ошибок,
  подготовка материалов на дни 15–91;
- **хранилище** (`db` + `user`): прогресс, карточки и ошибки в личной папке пользователя,
  одинаковые на телефоне и компьютере;
- **скачивание** (`downloads`): резервная копия прогресса.

Без claude.ai (просто открыть файл в браузере) работают все упражнения без Claude,
прогресс хранится в браузере.

## Сборка

```bash
python3 build.py      # → dist/gutachter-deutsch.html
```

Исправления учебных материалов применяются скриптом: `node tools/apply_patches.js patches.json --write`
(без `--write` — только проверка). Он же проверяет целостность данных.

Исходники в `src/`, порядок склейки задан в `build.py`:

| Файл | Что внутри |
|---|---|
| `src/data/course.js` | план на 91 день: темы, грамматика, сценарии |
| `src/data/vocab_w1_2.js` | слова и выражения, дни 1–14 |
| `src/data/grammar_w1_2.js` | грамматические блоки с упражнениями, дни 1–14 |
| `src/data/practice_w1_2.js` | тексты, сценарии разговоров, темы 4/3/2, банк вопросов собеседования |
| `src/core.js` | хранение, FSRS, озвучка, проверка ответов |
| `src/content.js` | сборка учебного дня, карточки |
| `src/prompts.js` | все инструкции для Claude |
| `src/ui.js`, `src/blocks.js`, `src/app.js` | интерфейс, блоки занятия, экраны |

Личные данные (резюме, самопрезентация) в репозиторий не попадают: они лежат только
в хранилище приложения на claude.ai (`data/users/<id>/profile`).
